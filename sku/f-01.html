What it is

A meta-model, not a model.

F-01 is the rules, scaffolding, and contract by which every other Turning Point Studio building block is constructed. It defines what an artifact has to look like to be an "electric utility reference architecture" — element naming, layer assignment, capability taxonomy, canonical data entities (CIM-aligned), integration-pattern shape, and customization rules.

If C-01 and T-01 are reference architectures for specific electric utility domains, F-01 is the spec those reference architectures conform to. It is also a usable standalone product: an electric utility EA team that licenses F-01 alone gets a complete starter kit for running an ArchiMate-based EA practice — they're simply not getting the domain-specific content C-01 and T-01 add on top.

Problem & boundary

What F-01 solves — and what it deliberately doesn't.

What F-01 solves

Every utility EA team that adopts ArchiMate or TOGAF burns 6–18 months rebuilding the same scaffolding. The work doesn't differentiate them; it just has to exist before anything useful happens in the modeling tool.

  • Utility A and Utility B's capability maps can't be compared, even when they do the same work.
  • A model built by Vendor X doesn't import cleanly into a model built by Vendor Y.
  • Integration patterns get reinvented per project because there's no organizational library.
  • The two-person EA team keeps getting pulled into project work because their reference work never gets ahead of demand.

What F-01 deliberately excludes

F-01 stays at the meta-level. Domain content lives in dedicated building blocks so each can be priced, licensed, and reviewed separately by a buyer's procurement and security teams.

  • NERC CIP control mappings — that's C-01.
  • Transmission operations content (EMS/SCADA, FERC 890) — that's T-01.
  • Distribution domain content (DER, AMI, OMS) — that's D-01 / D-02 / D-03 on the roadmap.
  • AI-augmented analysis tooling — that's the AI add-on (B-01 + B-02).
  • Implementation labor for your specific org — that's S-01 / S-02 (onboarding services).
The hard engineering call

The meta-model contract

The TOGAF Purist on the studio's review staff flagged this as the single most important artifact in the entire backlog. Budget 25–30% of Phase 1 time on the contract alone. The contract is what makes F-01 compose with C-01, T-01, and everything that comes after.

Stable

Cannot change without a major version bump.

  • Core ArchiMate element types and layer rules
  • Capability hierarchy at levels 1–3
  • Canonical entities (names, identity rules)
  • Standards-mapping anchors

Pluggable

Extension points for domain blocks.

  • Capability hierarchy levels 4+
  • Domain-specific entities (BES Cyber Asset, AMI Endpoint, DER)
  • Integration pattern specializations
  • Compliance overlays (CIP, FERC, NIST CSF)

Customer-customizable

Additive changes only. Extending, never renaming.

  • Naming aliases (preserves canonical mapping)
  • Additional attributes on canonical entities
  • Additional capabilities at levels 4+
  • Technology substitutions per the substitution notes

Forbidden

Breaks the contract. Named explicitly in the customization guide.

  • Renaming canonical entities
  • Changing layer assignments
  • Removing capabilities from the hierarchy
  • Restructuring the canonical model relationships

Build status & open questions

What's still being decided

F-01 is in active Phase 1 build. The questions below are tracked openly so design partners and early licensees know what's converging and what's still in motion.

  • Meta-model abstraction depth Stable-core vs. pluggable-boundary is the hardest engineering call. Being iterated through design-partner #1 build sessions.
  • Capability hierarchy levels 1–3 content How comprehensive should the utility-generic capability set be on day one? Lean (Helena's view) vs. comprehensive enough to map to a real org chart without forcing customization on day one (Janet's view). Decision pending.
  • Maturity assessment template — v1.0 or v1.1? AI Realist leans toward shipping the assessment with v1.1 once F-01 has been field-tested and we have real ground-truth scoring data.
  • CIM mapping completeness Full IEC 61968/61970 or the most-used 20%? Trade-off between signal of seriousness and time-to-ship.
  • Lead-magnet excerpt Can the customization guide and capability catalog be partially excerpted as a free preview without devaluing the licensed product? Customer Voice says yes; broader review pending.
